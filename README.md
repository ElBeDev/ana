# Ana Aguirre — Consultoría Estratégica & Soluciones Digitales

Landing de marca personal. Next.js 16 + Tailwind 4 + GSAP + Lenis.

## Desarrollo

```bash
npm install
npm run dev
```

## Editar contenido

Todo el texto, la trayectoria y los datos de contacto están en `src/content/site.ts`.
Mientras `contact.whatsapp`, `contact.email` y `contact.linkedin` estén vacíos, los CTAs
llevan a la sección de contacto y el botón flotante de WhatsApp no aparece.

## Imágenes

Están en `public/img/`. Los visuales de servicios, experiencia y "ruido" son composiciones
propias; se pueden reemplazar por fotos reales con el mismo nombre de archivo.

El plan completo del sitio está en `PROYECTO.md`.
